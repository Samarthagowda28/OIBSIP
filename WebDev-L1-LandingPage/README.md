# NovaTech - Landing Page

## OASIS INFOBYTE SIP - Web Development & Designing

### Task
Level 1 - Task 1: Landing Page

## Project Overview

NovaTech is a modern technology solutions landing page designed to present a fictional technology company and its services in a clean, professional, and responsive layout.

The website demonstrates the use of HTML5 and CSS3 to create a visually polished static landing page.

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Responsive Design
- Media Queries

## Features

- Fixed navigation bar
- Navigation links for Home, Services, About, and Contact
- Hero section with headline, description, and call-to-action button
- Services section with three service cards
- About section describing NovaTech
- Contact call-to-action section
- Footer with social media links
- Consistent blue, white, and dark color palette
- Hover effects for buttons, links, and service cards
- Smooth scrolling navigation
- Responsive layout for desktop, tablet, and mobile screens
- Proper spacing, alignment, and box sizing to avoid element overlap

## Sections

### 1. Navigation Bar
The navigation bar contains the NovaTech logo and links to the main sections of the website.

### 2. Hero Section
Introduces NovaTech with the headline:

> Build the Future with NovaTech

It also contains a short description and an "Explore Our Services" call-to-action button.

### 3. Services Section
Displays three major services:

- Web Development
- AI Solutions
- Cloud Services

### 4. About Section
Provides a brief introduction to NovaTech and its focus on creating innovative digital experiences.

### 5. Contact Section
Contains a call-to-action encouraging users to get in touch with NovaTech.

### 6. Footer
Contains the NovaTech brand name, social media links, and copyright information.
