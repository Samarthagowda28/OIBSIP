## Project Overview

This project is a personal portfolio website created to showcase my
background, technical skills, projects, and contact information.

The portfolio is designed using HTML5 and CSS3 with a responsive layout
for desktop, tablet, and mobile devices.

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Responsive Design
- Media Queries

## Features

- Fixed navigation bar
- Smooth scrolling navigation
- Hero/profile section
- About Me section
- Technical Skills section
- Featured Projects section
- Contact section
- LinkedIn and GitHub links
- Responsive desktop and mobile layout
- Hover effects
- Consistent blue, white, and navy color theme
- Avatar/profile placeholder
